# Wurst 索引成员写入触发 IR 替换失败

## 现象与环境

精灵短时效果的 parser/typecheck 已通过，但生成 IR 时抛出 `Node is not attached to a tree`。栈落在 `MultiArrayEliminator.java:160 → Replacer.java:22`，尚未生成可验证地图。

环境固定为 JDK `27+35-2325`、legacy 编译器 SHA256 `7d8cff387b98a4d1b3ad42a4b9f1b0829849c1c68abe2e794b776f5b110abac5`、Grill SHA256 `c5afe67aa5eeabfb98f0ec2f3f0831d8ffc2f4199c26b89eb7418f14319f9f87`、stdlib tree `90b45617eda50c15703e8cb2ec3241d3c7b61816`。没有更换锁、关闭优化或编辑生成 JASS。

## 关键线索与无效方向

- 查询锁定 jar 的 bytecode，定位该分支处理多索引 `ImVarArrayAccess` 的读取替换；替换对象的 parent 已为空。它缩小了嫌疑范围，但并没有证明某个业务数组必然是根因。
- 将 class 内 `vec2` 数组换成已有道路值快照、平行 real X/Y 数组，仍然报相同错误。
- 将索引 `+=` 展开成显式读写也未解决。不能仅凭源码看起来复杂就把一次未复编的改写记为成功。
- 保留函数局部 `vec2 array points`；它不是该报错路径的必要条件，JASS 文法也允许 local array。

## 最终定位与改写

直接通过 `cast.targetPositions[index].position = ...` / `.retired = ...` 访问 class 索引表中的另一个 record，会在锁定转换链的多索引展开中触发 detached-node 替换。先把索引 record 读入局部引用，再读写该 record 的字段，实际编译通过：

```wurst
let positionState = cast.targetPositions[index]
positionState.position = position
positionState.retired = true
```

`d284545aec5592a098a34815f65592821419add4` 落实等价的局部捕获。容量、目标身份快照、写入时间、清理所有权和几何数值都保持原契约。这里定位的是此锁定后端的触发形态，不将其泛化为所有 Wurst tuple/class 数组都会失败。

## 后续独立门禁

IR 通过后，旧 JASS 的每函数最多31参数门禁暴露四个过长调用。把道路第一个点恢复为已保存的 center，只传 second/third/fourth，删除恒真的旧 active-slot 参数；constructor31参数、公开 start30参数。没有削减身份或位置信息。

两处 mixed `and/or` 条件随后改成嵌套 if，以让受限 Python 回放器覆盖。pjass primary 文法中 OR 优先级高于 AND，原生成式与源分组一致；未证明原生布尔语义错误，这只是保义改写与验证工具覆盖补充。

## 验证与残余风险

执行 `tools/Run-WurstLinux.py checks`，再串行 `build`，使用上述锁定 tools/JDK/stdlib：

- r13 checks：PASS，包括实际 Wurst 测试。
- r2 build：PASS；实际成品147 allocator、31参数/8192数组边界、CD、启动及927 imports逐字节门禁通过。
- 成品 SHA256 `611ee1b735c56dc8b2a27cbe1db7e17469d1e536f1000f278a5bf3ea2f65a3e3`；延时/身份/取消负例和十Hero链使用此图实际 packed JASS 回放。20元素正常链在r1通过且与r2对应函数逐字相同；最终工具完整入口也在r2重新执行20族及全部负例并通过。
- 源码变化是业务等价展开；没有修改编译器源码或锁。未启动 Warcraft III，原生画面、运动、控制表现及性能仍未实测。

## 可复用经验与可提炼技能

1. parser/typecheck、IR 转换、Legacy JASS门禁、实际产物门禁是不同阶段，要分别记录首个失败。
2. 用锁定二进制的栈和 bytecode 缩小范围，再以一次局部等价改写和复编证明归因；保留失败尝试，避免事后把第一次猜测当成根因。
3. 嵌套索引 record 字段写入可先捕获局部引用；不必改变对象池、引入新调度器或更换工具链。
4. 原生语法与 Python 子集解释器能力需区分，不能把解释器拒绝表达式报告成引擎 bug。

可提炼技能：锁定 Wurst IR 错误缩窄、索引 record 等价展开、分阶段后端门禁和实际脚本证据归因。
