# 伤害监听阶段只改事件值未生效

## 现象与范围

装备半血/Boss 条件增伤在普通伤害监听里调用 `DamageEvent.setAmount()`。源码和观察事件值看似正常，但锁定库不会将该阶段的改值写回 HP，因此真实增伤没有得到证明。此前探针 `amount/unreduced=1` 也不能证明破甲：两个值可能都是同一原生伤害事件快照。

## 环境与关键线索

地图为 JASS、pre1.29 标准库目标，实机为 Warcraft III 1.27.0.52240。`wurst.build` 指定依赖源码 `E:/WurstToolchain/WurstStdlib2-source:pre1.29`；实际核验其中 `wurst/event/DamageEvent.wurst`。构建拷贝不是源码真相，依赖只读，不直接修改。

`onUnreducedDamage()` 从 `GetEventDamage()` 建立事件，运行早期监听后，存在 `life += amount - dmg.amount` 与 `target.setLife(...)` 的 HP 调整路径。这里的 `GetEventDamage()` 不是可由 API 名称保证的护甲前攻击值。

普通攻击随后通过零时延计时器进入 `onDamage()`，它先将事件切到 reduced 状态，再运行 `addListener()` 注册的监听，最后销毁事件；普通监听修改 `amount` 后没有额外 HP 写回步骤。接口名称及示例注释不足以证明该阶段的修改会生效。

## 无效验证及原因

- 普通监听调用 `setAmount()`：只修改事件对象，缺少实际 HP 写回。
- 比较 `getAmount()/getUnreducedAmount()`：对当前库可能只是同一原生事件值之比，不能证明原始面板伤害或护甲减伤。
- 只读技能等级：不能证明负护甲生效、等级刷新影响原生伤害或技能冷却。
- 仅比较两次自然普攻扣血：骰子、攻击装备、目标回血和飞行弹道可污染样本，需要固定物理伤害与独立无伤害回血基线。

## 修复与验证设计

条件追加改为早期监听捕获来源、目标、路线、命中前 HP/maxHP、原生事件值和装备。追加量为原生事件值乘半血与真正 Boss 比例之和。延后到安全帧，重验本局/路线、来源塔、目标存活与未漏怪；原击致死时跳过。同塔来源、code 标记和独立 `Eadd` ID 防止装备、宝宝、分裂箭及尸爆递归。

历史第一阶段曾采用 `ATTACK_TYPE_NORMAL + DAMAGE_TYPE_UNIVERSAL`，当时尚未实测。后续 TEST-0109 已证明该通道对英雄 Boss 再次施加 25% 法术减免，因此已撤换。最终源码采用标准双参 `CHAOS/UNIVERSAL`，该通道在本段历史阶段尚待验证；文末 TEST-0129 已给出 Boss 固定量与条件追加的真实 HP/事件证据。

宝宝倍率保持原样，文案改为随宿主普攻成长；开发说明明确基数是本次原生伤害事件值，排除条件追加段，不再承诺护甲前伤害。

有限 opt-in 探针保留实际 HP 和事件证据，cleanup 后仍可查询，下一次 start 才清空结果：

- 固定物理 100：无破甲、真实原生普攻挂破甲、卸装并等超过 3 秒后。
- 固定 universal 10：不同护甲模板的真实 HP 扣减。
- 每个短窗口先测无伤害回血，暂停源并留足弹道时间，记录外来命中污染。
- 真正普攻测试半血上下、Boss/近卫、原击致死、追加击杀归属和来源移除；任何未形成目标场景的样本只记录观察，不冒称通过。

## 当前证据与未验证项

TEST-0036 已证明独立装备毒：一次普攻后卸装仍出现 3 次伤害、共 18；后续卸装普攻没有毒。风暴冷却中换装后的两轮实际间隔为 9.500/7.000 秒，3 次施法、10 次脉冲。该版本还实机确认 12 格布局及收藏图标正常。

历史第一阶段的条件追加实现和增强探针在本段记录时尚未验证；TEST-0109 后续证据见文末，已补固定物理、普通目标通用伤害及部分致死边界。此处为历史待办，最终 `CHAOS/UNIVERSAL` 追加及英雄 Boss 数值已由文末 TEST-0129 对应样本验证。相关检查统一由父任务使用 `tools\Run-WurstChecks.bat` 和 `build-and-deploy-test-map.bat` 执行。

## 可复用经验与可提炼技能

从锁定版本的实际控制流追踪“监听读取/修改 → HP 写回 → 后续回调”，不要用 API 名字推断伤害阶段。原生行为验证采用实际 HP、无伤害基线、固定伤害、来源/目标过滤和污染标记，保存结果便于跨工具调用检查。

可提炼技能：pre1.29 伤害管线核验、有限原生 HP 对照探针、回血与弹道污染隔离、原生证据分层报告。


## TEST-0109 后续线索：Boss 追加再次被减免

固定物理 100 已实际测得 67.568 / 76.923 / 67.568，支持破甲生效及过期恢复；普通低/高甲的旧 NORMAL+UNIVERSAL 固定 10 都扣 10，但这没有覆盖英雄 Boss。

真正 Boss 的追加致死样本：preHP24.508、native18.023、应追加10.273，实际 Eadd7.705（75%），追加击杀归属仍为同塔 P1。锁定库将 `ATTACK_TYPE_NORMAL` 识别为 spell，英雄 25% 法术减免解释了差值。不能把“UNIVERSAL 绕护甲”进一步推成“任何目标均不受其它减免”。

Astra 批准将生产追加改成标准库双参伤害，使用 false/false、CHAOS/UNIVERSAL。探针固定通用量同步这一调用，并新增 Boss32 非致死 fixed10 与旧 NORMAL 通道对照。这描述 TEST-0109 修正后的历史状态；后续 TEST-0129 已构建并验证该 Boss 通道及条件追加。
