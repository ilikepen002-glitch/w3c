# Wurst 地图开发

本技能负责开发方法与领域知识。项目约束、风险分层、模型协作、验证命令和交付要求统一遵循 [AGENTS.md](../../../AGENTS.md)，这里不另设流程门禁。

## 定位与实施

区分现象、复现条件和假设，找到规则或状态的归属以及最近的可运行例子，再决定改法。已有上下文足够时直接使用；只读取本次决策需要的源码、测试和配置字段，不例行扫描整个项目。

- 游戏规则、状态、触发和物编属于 Wurst；依赖、staging、打包与部署属于配置/构建脚本；地形、装饰、布局和适合视觉调校的路径阻挡属于 World Editor。跨代码/编辑器任务先完成代码，列出剩余编辑器步骤。
- 物编使用既有 wrapper 和 rawcode 分配模式。检查修改字段及其直接引用：改图标核对图标路径；改 rawcode 核对唯一性与引用；改升级/技能/建造关系时核对相应链路。不因修改一个字段全面检查无关物编。
- 初始化调整先查 import 方向与依赖；不以 `initlater` 掩盖可消除的依赖问题。不确定语法或 API 时优先找相邻有效用法。
