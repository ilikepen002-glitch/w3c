# 生成图片并接入 Warcraft III 地图

用于技能图标、透明纹理和模型附件美术。这里沉淀生成到打包的可靠链路，不固定某种美术风格、技能数量或进化玩法。

## 先确定交付物

- 图标：按游戏实际显示尺寸设计，主体轮廓清晰，缩小后再检查；需要禁用态时一并制作。
- 纹理：要求透明就使用图像工具的透明背景能力，保留真实 alpha；黑色背景或棋盘格图案不等于透明。
- 翅膀等附件：图片只能提供纹理，仍需模型、UV、材质、挂点和动画。区分原图、离线模型预览与实际游戏画面，不把概念图称为游戏效果。

用户要求使用 image 时，读取当前可用的 `imagegen` 技能并使用内置图像工具。没有明确要求时，按美术需求决定是否生成，不为已有可用资源强行重画；工具失败按其技能处理，不擅自换付费 API 路线。

## 保留源与确定性转换

将选定原图复制进工作区，记录用途、准确提示词和生成工具。项目引用不得只指向工具缓存；清单使用仓库相对路径。保留可重建的转换脚本和模型源，不手改打包地图来补资源。

本项目已有入口（从仓库根目录读取/运行）：

| 位置 | 作用 |
| --- | --- |
| `assets/source/`、`imagegen-manifest.json` | 原图、提示词、模型源及离线预览 |
| `tools/BuildEvolutionAssets.py` | PNG 缩放、BTN/DISBTN、带 alpha 和 mip 的 BLP1；生成当前双翼 MDL |
| `tools/asset-converter/convert.cjs` | MDL 转 MDX800、重新解析模型与 BLP 检查 |
| `tools/asset-converter/README.md`、包依赖锁 | 依赖与重建命令；不提交 `node_modules/` |
| `imports/` | 打包资源；目录层级对应地图内路径 |
| `tools/VerifyEvolutionArtifact.py` | 读取实际地图的 W3U/W3A、图标与模型纹理引用 |

这些工具目前面向已有英雄图标和双翼，不是任意美术资产的通用转换器。复用前检查输入、输出范围及依赖，只在源资产变化时重建；仅修改技能说明无需运行它们。新需求超出范围时再作最小扩展。

当前图标采用 64×64 BTN/DISBTN，双翼纹理采用 512×512；这是现有资产参数，不是所有资源的硬限制。检查尺寸、透明通道、mip 链和目标补丁支持。某些图片读取器不能完整解码 BLP1 alpha，应用 Warcraft 格式解析器核验，不仅凭通用预览判断透明度。

## 引用路径：两类已复现陷阱

**完整图标路径被快捷方法重复加前缀。** 当前标准库的 `presetIcon` 会处理路径，直接传入 `war3mapImported\BTNName.blp` 曾产生 `ReplaceableTextures\CommandButtons\war3mapImported\BTNName.blp`。自定义完整路径用项目物编的显式 `setIconNormal`、`setIconResearch` 等设置，按技能类型检查自动施放/关闭图标。不要因此修改标准库拷贝，也不要把此行为假定为所有版本都相同。

**源码转义与资源路径混淆。** Python、MDL、MDX 各层文本规则不同；源码里看起来正确的反斜杠，可能在 MDX 的 `TEXS` 中成为两个连续分隔符。校验最终解析出的完整路径，再从实际地图 MPQ 按该路径提取纹理。只查文件名子串、只检查 imports 中有文件，都抓不住这个问题。

同样核对 W3A 的 `aart`、`arar`、`auar`、W3U 模型/图标和禁用图标路径。自定义资源应能从当前地图提取；引用原生资源时从目标安装包确认存在，不要求它们都打进地图。

## 运行时与离线验收

永久附件由运行时状态持有 effect，明确出售、死亡、失守、结束时的清理责任。持续展示使用合适的循环动画；不要反复创建一次性特效来模拟永久翅膀。按宿主模型调整尺寸与挂点，先检查目标格式、几何、材质透明/双面属性、动画区间及循环标志。

资产或接线变更后按项目规定串行执行相关 Wurst 检查、唯一构建部署脚本，再检查本次地图对象和资源的精确引用及源/部署哈希。转换器通过不代表打包成功，历史产物通过也不能替代本次产物；只运行与本次变更有关的 verifier。

验收分清三个层次：图片小尺寸/alpha 预览、模型与打包字段验证、游戏实际显示及性能。默认完成前两层。没有明确实机请求时不启动游戏、不顺便运行探针；简要披露挂点遮挡、动画观感和实际帧率未实测即可。

本次经验的证据与参数见仓库 `docs/validation/2026-10-10-玩法反馈与自动进化.md`，仅在需要追溯时读取，不把历史通过结果当作新任务验证。
