# 电脑控制与故障恢复（按需读取）

底层 API 以当前 `computer-use:computer-use` 技能为准。此前已验证入口为 `node_repl` 的 `@oai/sky`，可发现 `mcp__node_repl__js` 后按其文档使用：

```javascript
if (!globalThis.sky) {
  const { sky } = await import('@oai/sky');
  globalThis.sky = sky;
}
```

浏览器 cua_repl 原生桌面禁用不代表 sky 不可用，不因选错入口放弃。保存真实游戏窗口与最新状态；每次动作立即刷新，只操作已观察控件，不复用旧截图索引/坐标。

现有窗口先观察并复用。无窗口时用底层允许的启动 API 启动 Frozen Throne.exe。启动器可能迅速退出交接给 war3.exe；即使启动调用未找到窗口，也先刷新窗口列表，按标题 `Warcraft III` 和 war3 进程确认唯一目标，避免重复启动。

当前授权允许退出测试而 Stop-Process 拒绝访问时，对已确认游戏窗口发送 Alt+F4；立即刷新，看到确认退出后点击“退出(X)”，再刷新窗口和进程确认结束。不把确认框当作已退出，不反复提升权限。

- 转场空面板：短暂等待再观察，不盲重按。
- 窗口最小化/失效：按底层技能恢复并重新获取窗口，不猜旧句柄。
- 窗口消失：核对进程/窗口和游戏目录 `Errors\*Crash.txt`、`*Crash.dmp` 是否新增，区分主动关闭与崩溃；历史日志不是本次证据。
- 复制失败：保留错误并检查文件占用，不以旧图冒充新图。
- 用户停止控制：停止 UI 并说明停点，等待明确恢复授权。
