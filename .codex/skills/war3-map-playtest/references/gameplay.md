# 玩法验证（按需读取）

只验证当前目标。链路验证止于载入、工人可操作和首波；单 bug 复现覆盖对应现象，不自动扩成全部装备或全 32 波。代码、环境及复现条件无相关变化时复用已有通过证据，不重复整套。

- 工人通常未自动选中。此前可用 F8 选空闲工人；操作后核对选中对象与菜单。
- 此前首波延迟 30 秒，以当前源码为准；等待期间可检查当前目标所需菜单、建塔和镜头，避免重复截静止画面。
- 在用户授权的隔离试玩局里，可按需使用已有 `-addMoney 10000` 加速升级；先确认源码支持，核对聊天焦点后输入并验证金币变化。不在真人多人局默认使用，不把测试金币计为经济验证。
- 建塔后观察进度完成再操作下一阶，不盲连点。
- 需要原生行为诊断探针时，按需读取项目 `docs/playtests/native-probes.md`（若存在），选择与复现目标直接相关的探针；不默认执行全部命令或长场景。
