# 原创来源与使用边界

本项目按照用户的蚀月黑紫施法者概念及后来提供的魔兽经典黑暗风格参考，原创编写网格、骨架、动作、UV与diffuse纹理。参考仅用于审美方向，没有复制其模型数据、贴图像素、Logo或其他作者资源。

用户在 2026-10-13 对 v3 静态图回复“可以”，确认脸危险感与材质方向，随后要求完成动画并交生产接入。该认可不等于客户端已验收。

所有本包模型/纹理/生成源为用户项目原创产物，可随本项目交接与入库；没有附带需要另求裸资源再分发许可的第三方模型/纹理。第三方软件依赖（Blender、Pillow、mdx-m3-viewer 等）只列出环境信息，没有重新分发其软件包。没有改写或触碰另一个 Boss 的 King Leoric 原作者资源或许可。
